Обновление 0.6.1:
- На странице оригинального BGS проверено описание FALL: осенняя зона, 3 яйца, обновлённый спавн, Bubble Pass 26, задания и магазин события.
- Поиск яиц теперь учитывает вложенные папки Eggs и перенесённые Hotkey с точным EggName или записью EggModule. Декоративные модели без признаков яйца пропускаются.
- В «Островах» появляются загруженные области события; область внутри Overworld остаётся локальной точкой, без вымышленного SetWorld("Autumn").
- «Только яйца события» фильтрует список. Названия, цена и валюта берутся из доступных данных игры. Новая валюта распознаётся и для подбора.
- После удаления / повторного появления модели выбор перепривязывается. Открытие из любого места продолжает работать для яйца, которое остаётся в EggModule; при отсутствии и модели, и метаданных запросы приостанавливаются.
- Списки обновляются при появлении объектов карты; диагностика содержит найденные яйца, области и цены.
- Осенние названия яиц, цены, координаты, команды заданий и магазина не выдумывались. Доступа к живой структуре нового сервера здесь нет; проверены макеты и компиляция, а не работа в конкретном исполнителе.
Источник описания обновления: https://www.roblox.com/games/2512643572/Bubble-Gum-Simulator

Что добавлено / исправлено:
- Выбор 9 базовых и новых загруженных миров во вкладке «Монеты». Выбор переводит в мир и включает область «весь мир».
- Переключение области фарма: текущий остров или выбранный мир.
- Учитываются обе структуры карты: FloatingIslands/<мир> и Worlds/<мир>/Islands.
- AFK сундуки во вкладке «Острова»: 23 пункта с индивидуальным выключением.
- Сундук: переход в мир → посадка на поверхность → подход → попытки получения → проверка Regen/Prompt → возврат в прежний мир и точную CFrame.
- Между поездками есть время для обычного фарма. Включённые пользователем функции сохраняются; их флаги не перезаписываются после поездки.
- Монеты: вложенные папки/модели, появление/удаление объектов, прозрачные touch-hitbox, фиксированное направление прохода через монету, пропуск неподбираемой цели.
- Яйца: одиночный PurchaseEgg либо один PurchaseEgg(..., "Multi") для тройного открытия; ручная кнопка использует выбранное количество.
- Открытие из любого места не управляет персонажем и допускает одновременный сбор монет.
- Shiny/золотые: группы по 10 обычных петов из данных инвентаря, исключены экипнутые и закрытые. Один запрос на неизменившийся состав группы; повторный запуск переключателя сбрасывает ожидание.
- Зелья: выбор из 9 рецептов; заполнение свободных слотов BrewingFrame и ClaimPotion только для готовых. Если интерфейс лаборатории ещё не создан игрой, открыть его один раз.
- Мини-игры: Match The Pet (память карточек, поиск пар), Spin To Win (бесплатное вращение по времени), Doggy Jump (запросы этапов по протоколу старого BGS).
- Общий стоп / закрытие / перезапуск / смена персонажа отменяют отложенные действия. Ручной ТП имеет приоритет перед поездкой к сундуку.
- Anti-AFK, общий бюджет сетевых запросов, не более одного незавершённого InvokeServer.
- «Скопировать диагностику» находится во вкладке «Авто».

Это не тест в живом Roblox-клиенте. Совместимость конкретной копии Legacy и исполнителя требует проверки в игре.

Ограничения:
- Переходы, ×3, удалённое открытие, рецепты и награды окончательно разрешает сервер игры.
- Если мир не загружен и WorldService недоступен, показывается причина; вымышленные координаты не используются.
- Сундук считается полученным только при смене состояния Regen/Prompt, а не по успешному FireServer.
- Без счётчика EGGS_OPENED нет подтверждения фактического количества открытых яиц.
- Если копия игры использует другой инвентарь/GUI/протокол, статус сообщает об отсутствующих данных.
- Автоматизация всех возможных мини-игр не заявляется: реализованы три перечисленных режима. Doggy Jump посылает команды этапов; успешное прохождение сервером в этой копии Legacy не подтверждено.

Разработка:
Редактировать v0_6/Logic.lua, Runtime.lua, UI.lua; затем python3 v0_6/build.py.
