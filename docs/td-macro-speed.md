# TD Macro 1.7.0 — скорость матча до ×3

Старый загрузчик остаётся прежним: `TDMacroPrototype.lua` в ветке `main`.

- «Макс. скорость ×3» последовательно переключает Z, читает ответ HUD и останавливается на ×3. Если цикл ограничен ×2/×1.5, возвращается на наибольшую увиденную скорость. При неизвестном значении не нажимает Z вслепую.
- Новые записи сохраняют время в игровых секундах: интервал умножается на скорость, действовавшую в этом интервале. Переключение скорости не пересчитывает прошлое.
- Основная привязка действий — номер волны и игровое время от её начала. При позднем подключении остаётся резервная привязка к StartedAt. Ввод и камера используют один согласованный счётчик с паузой.
- Существующие времена событий и формат конфигурации сохранены; новые поля добавляются рядом. Привязки карт, записи, настройки доступа к файлам, серверные действия и проверка денег не удаляются.

## Старые записи

До 1.7.0 фактическая скорость не записывалась. Первоначальная оценка — ×2 при сохранённой настройке `x2=true`, иначе ×1. Настройка не доказывает реальную скорость записи. В «Макросах» выбери старую запись и нажми **«Записано ×… · изменить»**, чтобы циклически выбрать ×1 / ×1.5 / ×2 / ×3. Это скорость исходной записи, а не желаемая скорость текущего матча.

Если старый макрос записывался с несколькими переключениями скорости, восстановить эту историю по старому файлу точно невозможно: для точной адаптации нужна новая запись. При подключении скрипта посреди волны история переключений до подключения тоже неизвестна; точная привязка возобновляется со следующей наблюдаемой границы волны. Распознавание скорости опирается на существующий HUD игры; недоступная скорость не разблокируется.

## Проверка

```bash
luau-compile TDMacroPrototype.lua >/dev/null
LUAU_BIN=/path/to/luau python3 tests/td_macro/run.py
```

14 групп регрессионных проверок извлекают настоящие функции из скрипта: все 16 сочетаний записи/запуска ×1/×1.5/×2/×3; смена скорости; пауза; сохранение метаданных; сброс волн и матчей; резервные тайминги; отмена; поведение Z при ×3, ограниченном цикле, неизменном и неизвестном HUD. Проверки не заменяют запуск в Roblox: актуальная отрисовка HUD и ответы сервера в живой игре здесь не проверялись.
