# T33 — голограмма вокруг персонажа

## Завершение управления — T34

- Скрытая голограмма после повторного запуска больше не открывает старое окно автоматически. Фарм не останавливается.
- Рядом с переключателем видимости есть постоянная кнопка «МЕНЮ». Она открывает полные настройки даже при скрытом HUD, респавне или камере от первого лица.
- Питомцы листаются стрелками по три: доступны все экипированные питомцы, включая комплекты из 7–9. При изменении комплекта страница корректируется; временное отсутствие данных не закрывает интерфейс.
- «Сессия → Цель» открывает карточку прогресса на телефоне, из неё доступны настройки ребиртов. Выбранная вкладка запоминается; навигация переведена на русский и английский.
- Ошибки действий показываются прямо поверх игрового экрана. Более раннее сообщение не может погасить новое. Скрытие убирает сообщение.
- Перетаскивание отменяет клик, даже если палец вернулся на исходное место. Респавн, смена камеры, поворот экрана, поле ввода и меню Roblox отменяют удержание. Кнопки становятся активны после раскрытия панелей. Скрытие отменяет ещё не выполненный клик.
- Ошибка одного обработчика при очистке не мешает удалить остальной HUD; завершение основного скрипта защищено от ошибки очистки интерфейса.

Проверки T34: 27 сценариев HUD, 65 сценариев существующей автоматики, компиляция Luau и проверка совпадения встроенного модуля. Проверки границ Roblox API выполняются с имитацией движка; реальный клиент Roblox из этой среды недоступен.

Прежний файл запуска `RockBugHub_v1_5.lua` теперь содержит весь интерфейс. Дополнительный `loadstring`, импорт модели или установка ассетов не нужны.

- «СКРЫТЬ / ПОКАЗАТЬ · RB» слева сверху и Right Shift переключают видимость. Фарм при этом продолжает работать.
- MENU открывает прежнее окно с полными настройками. «ПОКАЗАТЬ · RB» возвращает голограмму.
- На широком экране панели расположены по сторонам персонажа. На телефоне AUTO / PETS / WORLD / STATS переключают активную панель. В вертикальном режиме панель находится под персонажем.
- Автоматика использует существующие переключатели гантели, ребиртов, тренажёра и фонового босса. Телепорты вызывают существующий адаптер. Статистика и имена питомцев читаются из текущего runtime; сила в секунду измеряется по приросту за интервал, FPS — по кадрам.
- При скрытии убираются все панели, кольца и кристалл, отключаются обработчик нажатий и покадровое обновление. При перезапуске старый HUD полностью уничтожается. Учитываются смена камеры, респавн и ультра-режим. При слишком близкой камере 3D-панели временно убираются; кнопка возврата остаётся.

`src/HologramHUD.lua` — исходник. После изменения выполнить `python scripts/build_hologram.py`; `--check` проверяет совпадение со встроенной копией.

Панели — SurfaceGui на локальных Part, эффекты — Beam. Все Part имеют `CanQuery=false`, `CanTouch=false`, `CanCollide=false`. Координаты нажатия переводятся в плоскость Back (+Z), поэтому голограмма не участвует в лучах и касаниях игрового мира. Нажатие подтверждается отпусканием на той же кнопке без перетаскивания; игровые кнопки, меню Roblox и поле ввода имеют приоритет.

Концепт кристалла создан генератором изображений и сохранён в `assets/hologram/crystal-concept.png`. Fal отклонил генерацию из-за исчерпанного баланса, to3D вернул ошибку генерации. Рабочий кристалл собран из нативных рёбер по мотивам концепта, а не загружен как сгенерированная 3D-модель.

Проверка: Luau compile; 17 сценариев геометрии, нажатий и жизненного цикла HUD; 65 существующих сценариев сундука, возврата и восстановления тренажёра. Компоновка дополнительно проверена по проекциям созданных GUI-узлов для 1536×864, 844×390 и 390×844. Проверки используют имитацию границ Roblox API; визуальный запуск в настоящем клиенте Roblox из этой среды недоступен.
